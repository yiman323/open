# 课程资料整理工具

## 一句话简介

一个面向学生和自学者设计的命令行小工具，用于按课程和日期整理学习资料。它希望减少文件散落、重复命名和查找困难的问题，让使用者能快速定位某门课程、某个学习阶段的相关材料。

## 项目状态

> **项目状态：设计阶段（课程练习）。** 当前版本尚未实现可运行的命令行程序，也没有发布安装包。本 README 只描述已经存在的内容和后续设计，不把计划功能写成已完成功能。

| 项目项 | 当前情况 |
| --- | --- |
| 目标用户 | 需要整理课程笔记、讲义、作业和参考文献的学生、自学者 |
| 主要用途 | 按课程与日期归档资料，为后续检索提供统一结构 |
| 当前可用内容 | 项目说明、许可证和许可证选择分析 |
| 当前不可用内容 | 文件扫描、自动归档、全文检索及命令安装 |
| 许可证 | MIT |

## 安装或获取

当前处于设计阶段，**暂无安装包和可执行命令**。可以获取本仓库并查看设计资料，支持 Windows、macOS 和 Linux：

```bash
git clone https://github.com/yiman323/open.git
cd open
```

获取仓库需要安装 Git，或从 GitHub 页面下载源码压缩包。当前阶段不要求安装 Python 或其他运行依赖。

## 使用说明

当前版本不能执行资料整理。最小的有效操作是：

1. 打开本 README，确认项目目标、状态和目录结构；
2. 阅读 [`compliance-analysis.md`](compliance-analysis.md)，了解许可证选择和使用边界；
3. 在 Issues 中反馈目标场景、文件命名规则或希望优先支持的课程结构。

后续计划提供 Python 3.11+ 命令行版本，用于扫描资料目录、按课程与日期生成归档建议。**该功能目前尚未实现**，因此不提供虚假的安装或运行命令；实现并验证后会在此处补充真实用法。

## 如何贡献

项目目前处于方案阶段，欢迎通过以下入口参与：

- 在 [GitHub Issues](https://github.com/yiman323/open/issues) 提交使用场景、目录结构建议或设计问题；
- 通过 [Pull Requests](https://github.com/yiman323/open/pulls) 修正文档、补充许可证说明或参与后续实现；
- 提交内容时请说明改动目的，保留已有版权和许可证声明，不提交账号密码、访问令牌、个人隐私或未获授权的资料；

提交代码前应先通过 Issue 对齐目标或说明实现方案；当前尚无自动化测试，后续加入代码时需同步补充可重复执行的验证步骤。
